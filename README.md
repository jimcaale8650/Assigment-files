# Assigment-files


University Course Registration System
Overview
A Windows Forms application built in C# designed for university registration offices to calculate student tuition fees, manage course selections, and apply discount structures based on study levels and selected services.

Features
Input Validation & TryParse: Securely validates user inputs and prevents conversion crashes for courses and study years.

Dynamic Fee Calculation: Automatically computes tuition fees based on study levels (Year 1 to Year 4) and course counts (1 to 8).

Service Options & Discounts: Automatically calculates service fees (accommodation and transport) and applies percentage-based discounts for bulk course registrations.

UI Controls: Utilizes textboxes, buttons, and event-driven logic for user interaction.

Technologies Used
Language: C#

Framework: .NET / Windows Forms

Environment: Microsoft Visual Studio

How to Run
Clone or download the repository.

Open the solution file (.sln) in Visual Studio.

Build and run the project (F5) to test the registration interface.
